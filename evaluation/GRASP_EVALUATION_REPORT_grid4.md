# 机械臂仿真抓取系统 —— 分层指标评估报告

生成时间：2026-10-14 19:55

> 系统：ROS 2 Humble + MoveIt 2 + Gazebo Sim (Fortress)，Franka Panda 两指夹爪，
> 感知链路：YOLOv8-seg 2D 实例分割 + 点云 DBSCAN 聚类/拆分 + 预训练 GraspNet 6DoF 抓取检测。

## 1. 实验设置

- 系统层采集：headless 完整系统，`continuous: true` 连续抓取，每轮跑到任务 DONE 或 480s 上限；共 **10 轮**有效运行。
- 场景摆放：每轮全新启动仿真，采用**固定初始布局**（2×2 紧凑网格，边界间距 20mm），以隔离物理/时序噪声、保证指标可复现可对比。
- 感知层评估：离线在合成验证集（29 张 / 116 个实例，含真值多边形）上评估 YOLOv8-seg；每张图均经随机化摆放采集，与在线场景同源。

## 2. 感知层（YOLOv8-seg 2D 实例分割）

| 指标 | 数值 | 说明 |
|---|---|---|
| **mAP@0.5 (Mask)** | **0.995** | 掩码平均精度均值（IoU 阈值 0.5） |
| mAP@0.5:0.95 (Mask) | 0.6067 | 掩码 mAP（IoU 0.5:0.95 平均） |
| Mask Precision | 0.9833 | 掩码精确率 |
| Mask Recall | 0.9983 | 掩码召回率 |
| **平均 Mask IoU（匹配实例）** | **0.8853** | 预测掩码与真值掩码的交并比均值（IoU≥0.5 贪心匹配） |
| 实例检出率 | 100.0% | 命中实例 116/116 |

各类别平均 Mask IoU：

| 类别 | red_cube | blue_cylinder | green_bar | yellow_box |
|---|---|---|---|---|
| 平均 IoU | 0.8686 | 0.8925 | 0.8873 | 0.8926 |

**结论**：合成场景中物体为纯色几何体，YOLOv8-seg 的 mask mAP@0.5 达 0.995；在物体两两紧邻（DBSCAN 会将其并为一团）的场景下，分割掩码的平均 IoU 仍达 0.8853，可有效在 2D 上把粘连实例切开，为下游点云按类别拆分粘连簇提供可靠依据。

## 6. 指标口径与测量方式

| 指标 | 定义 | 采集方式 |
|---|---|---|
| mAP@0.5 (Mask) | 掩码 AP 在 IoU=0.5 下的均值 | ultralytics `val()`，与训练日志同口径 |
| 平均 Mask IoU | 命中实例（IoU≥0.5 贪心匹配）预测掩码与真值掩码 IoU 均值 | 自实现逐实例匹配 |
| 规划成功率 | MoveIt 运动请求成功数 / 请求总数 | `MoveGroupClient` 埋点计数 |
| 空抓率 | 闭合到底未夹住次数 / 闭合尝试次数 | 抓取执行节点埋点计数 |
| 综合抓取成功率 | 成功夹起并搬运放置次数 / 尝试次数 | 抓取执行节点计数 |
| 放置成功率 | 成功搬运投放次数 / 抓取确认（夹住）次数 | 抓取执行节点计数 |
